# add 関数の仕様

2つの整数を加算し、その結果を返す関数です。

## 関数宣言

```c
int add(int a, int b);

```

## 引数

| 引数名 | 型 | 説明 |
| --- | --- | --- |
| `a` | `int` | 加算する1つ目の数値 |
| `b` | `int` | 加算する2つ目の数値 |

## 戻り値

| 型 | 説明 |
| --- | --- |
| `int` | `a` と `b` の和（`a + b`） |

## 使用例

```c
#include <stdio.h>
#include "add.h"

int main(void) {
    int result = add(3, 5);
    printf("3 + 5 = %d\n", result); // 出力: 3 + 5 = 8
    return 0;
}

```

## 注意事項

* 引数および戻り値の型は `int` です。オーバーフロー（`INT_MAX` を超える加算）が発生した場合の動作は未定義となります。
